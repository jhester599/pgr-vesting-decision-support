# PGR Monthly Decision Log

Automated recommendations generated by `cli/monthly_decision.py` on the 20th of each month
(or the last business day on or before the 20th when the 20th falls on a weekend).

Each production run writes a dated folder `artifacts/monthly_decisions/YYYY-MM/` containing:
- `recommendation.md`: the sell/hold report with tax context
- `diagnostic.md`: realised-only model health and the recommendation gates
- `signals.csv`, `benchmark_quality.csv`, `consensus_shadow.csv`,
  `classification_shadow.csv`, `decision_overlays.csv`
- `monthly_summary.json`, `run_manifest.json`, `dashboard.html`
- `plots/calibration_curve.png`

Dry runs (`--dry-run`) write to the gitignored `results/dry_run/monthly_decisions/`
and never append here. Rows marked `[DRY RUN]` below are history from before that
rule (review 2026-09-25, F14); they are not production decisions.

## Column Definitions

| Column | Description |
|--------|-------------|
| As-Of Date | The date the model uses as its information cutoff (the 20th, or the last business day before it) |
| Run Date | When the script actually executed |
| Consensus Signal | OUTPERFORM / UNDERPERFORM / NEUTRAL (live quality-weighted consensus across the eight primary benchmarks) |
| Sell % | Recommended percentage of the vesting tranche to sell: the 50 % tax default unless the month is ACTIONABLE |
| Predicted 6M Return | Live consensus 6-month PGR relative-return forecast |
| Mean IC | Equal-weight mean of the per-benchmark OOS ICs (the gated IC) |
| Hit Rate | Equal-weight mean directional accuracy (reported, not gated) |
| Notes | The recommendation mode and, when it is not ACTIONABLE, the gates that did not pass and why (from 2026-09-27, R3); `[DRY RUN]` marks historical dry runs |

---

## Interpreting the Recommendation

The mode comes from five gates (`docs/decision-output-guide.md`): OOS R² against the
prevailing mean, equal-weight IC, Pesaran–Timmermann directional skill, completed
walk-forward validation, and required inputs ready at the as-of date.

- **ACTIONABLE** (every gate passes): OUTPERFORM with a forecast above 15 % sells 25 %;
  OUTPERFORM otherwise sells 50 %; UNDERPERFORM sells 100 %; NEUTRAL, or an IC below
  0.05, sells 50 %.
- **MONITORING-ONLY** (no gate fails, one is marginal): sell the 50 % default.
- **DEFER-TO-TAX-DEFAULT** (any gate fails, including missing, stale or unknown inputs):
  sell the 50 % default.

The sell % recommendation is used only at actual vesting events (January and July). Monthly runs provide ongoing signal quality monitoring and early warning of trend changes.

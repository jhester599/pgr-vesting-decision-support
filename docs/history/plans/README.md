# Legacy Plans

This directory contains legacy v8-v34 Codex execution plans. It is part of
the project history (index: [`docs/history/README.md`](../README.md)).

These files are retained for auditability because older closeouts and archived
research summaries reference them.

Later plans (v37 onward) are in [`../superpowers/plans/`](../superpowers/plans/);
version closeouts and handoffs are in [`../closeouts/`](../closeouts/).
